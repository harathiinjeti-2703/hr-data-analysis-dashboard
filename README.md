📊 Power BI HR Analysis Dashboard
📌 Project Overview

The HR Analysis Dashboard is an interactive Power BI dashboard designed to analyze employee workforce data and provide useful HR insights.

The dashboard helps understand employee distribution, active employees, employee separations, new hires, age groups, gender, regions, tenure, pay type, and job type.

🎯 Objectives
Analyze employee workforce distribution
Compare Male and Female employees
Analyze employees by Region
Understand employee Age Groups
Track Employee Separations
Analyze New Hires
Compare Hourly and Salaried employees
Analyze average tenure by region and gender
Understand new hires by region and job type
